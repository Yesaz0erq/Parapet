# 鹦鹉性格、羽色遗传与雏鸟成长

主人可以**蹲下、空手右键自己的鸟**，在互动面板中查看名字、性格和亲密度。若它还携带一种与外观不同的羽色，面板会显示携带色，把鼠标移到羽色一行可读到英文 ID。全部 38 个实体都有性格。以下概率是 parapet 的游戏规则。

## 怎样读懂一只鸟的羽色

可变色鸟有两个羽色位。显色决定眼前看见的羽色，携带色可以传给后代。首次自然生成的鸟通常两者相同；旧版存档升级时，以它原有的羽色填入携带位。携带色与显色相同的鸟，每次都会传出那个颜色；两者不同的鸟，每个颜色各有 1/2 的传递机会。

例如，一只原灰玄凤可能携带珍珠。即使亲鸟外观一直是原灰，它仍可能把珍珠传给幼鸟。羽色与性格一起存入实体，重新进世界及用鸟笼搬运时都会保留。

## 两只亲鸟如何影响雏鸟

1. 让两只已驯服的成鸟离开笼子并取消停留，分别喂一份该鸟种的繁殖食物。秋草、月轮与巴布亚折衷需要雌雄配对。三种吸蜜鹦鹉吃西瓜片或甜浆果，其余鸟用小麦、甜菜、西瓜或南瓜种子。[鸟类照料](cages-and-care.md)
2. 每只亲鸟各传一个羽色。幼鸟选其中一个作为显色，另一个留在携带位。哪只亲鸟传来的颜色显现，由下面的性格权重决定。调换两只鸟的先后顺序，结果概率相同。
3. 若色目中还存在双亲四个羽色位都没有的颜色，幼鸟有 **1/16（6.25%）** 的机会将显色改成其中一个，所有候选新色等概率。携带位仍保留。若所有颜色都已在亲鸟的羽色位中出现，便直接显示第二步选中的颜色。

| 亲鸟性格 | 存档 ID | 显色权重 | 空闲时尝试理羽的间隔 |
| --- | --- | ---: | --- |
| 温和 | `calm` | 3 | 9–18 秒 |
| 好奇 | `curious` | 2 | 12–24 秒 |
| 大胆 | `bold` | 4 | 15–27 秒 |
| 害羞 | `shy` | 1 | 18–30 秒 |

显色机会等于该亲鸟权重除以双方权重之和。假设一只大胆的绿虎皮和一只害羞的蓝虎皮都仅携带自己的颜色，第二步选中绿的概率是 4/5。计入突变后，**绿雏 75%，蓝雏 18.75%，其他四种羽色合计 6.25%**。两只亲鸟性格相同时，显色选择各占一半。幼鸟的性格独立产生，四种各约 1/4。亲密度与亲鸟的主人归属各自独立于显色判定。理羽间隔按 20 TPS 计算，鸟在跟随、觅食等行为结束后才有机会开始理羽。

### 牡丹的异色配对

桃脸、费氏与面罩共用 `parapet:lovebird`。只要两只亲鸟的**显色 ID 不同**，幼鸟便从全目录 **122 款中等概率抽取显色**，每款 1/122，包括双亲的颜色。它还会携带一枚亲鸟传出的颜色，选哪位亲鸟贡献携带色仍按双方的性格权重计算。此规则允许不同牡丹组别在游戏中配对。[牡丹羽色目录](lovebird-colors.md)

当双亲显色 ID 相同时，改按普通双亲规则计算。若触发 1/16 的新色，只从该显色所属的桃脸、费氏或面罩组别选取；已携带的其他组别颜色仍可正常传递。

### 只在相应范围内变化的外观

- 玄凤、虎皮、绿颊、和尚、秋草、月轮以及有多种羽色或地域外观的伴侣鹦鹉使用各自的色目。绿颊的香吉士可以由亲鸟传下，也可以从候选新色中出现。[伴侣鹦鹉色目](companion-parrots.md)
- 黑头凯克与白腹凯克各自配对；刚果灰与提姆那灰各自配对；16 种金刚分别属于各自的实体。单一羽色的鸟种保留本种外观。[金刚鹦鹉名录](macaws.md)
- 巴布亚折衷按独立随机的性别显示雄绿或雌红蓝。秋草和月轮先决定幼鸟的羽色，性别独立产生并选用相应贴图。太阳锥尾、两种灰鹦鹉及其余幼鸟均自出生起显示自己羽色和性别对应的成鸟贴图。

## 求偶、成长和繁殖冷却

两只亲鸟各吃一份繁殖食物后会寻找伴侣、相互注视和靠近。它们配对约 **300 游戏刻（15 秒）**，彼此可见、相距不足 3 格时产下一只幼鸟，并保留原版的繁殖经验和玩家进度。原版求偶约 60 游戏刻，喂食后爱心窗口为 600 游戏刻（30 秒），两只鸟应尽量同时喂。

在正常 20 TPS、鸟持续加载并正常计时时，**雏鸟约 100 分钟成年，亲鸟交配后约 25 分钟可再次繁殖**。对应的原版时间为 20 分钟和 5 分钟。给雏鸟喂对应的日常食物会按原版规则缩短剩余成长时间。未加载或作为物品携带的鸟，其实体计时暂停。

每只雏鸟身边会偶尔落下一小点白色羽粉，方便辨认同色亲子。以下为世界中同种鸟的幼体与成年个体相比的线性尺寸。模型、碰撞箱和眼高使用相同比例，笼内展示额外按笼的空间适配。

| 体型档 | 幼鸟相对成鸟尺寸 |
| --- | ---: |
| 小型（虎皮、牡丹、秋草） | 100% |
| 中型 | 65% |
| 大型 | 50% |

升级后的旧存档保留原有成长进度比例。例如还剩 2 分钟长大的旧雏，在新规则下还剩约 10 分钟。手动指定的 `Age` 以游戏刻为单位，负值表示距离成年还有多久，正在繁殖冷却的成鸟使用正值。

## 命令查询与示例

在已启用命令的世界中，以下示例查询最近的一只玄凤，或召唤一只带指定性格和携带色的新生玄凤。显色和携带色都使用对应鸟种图鉴中的英文 ID。

```mcfunction
/data get entity @e[type=parapet:cockatiel,sort=nearest,limit=1] Personality
/data get entity @e[type=parapet:cockatiel,sort=nearest,limit=1] Plumage
/data get entity @e[type=parapet:cockatiel,sort=nearest,limit=1] CarriedPlumage
/data get entity @e[type=parapet:cockatiel,sort=nearest,limit=1] Age
/summon parapet:cockatiel ~ ~ ~ {Age:-120000,Personality:"bold",Plumage:"gray",CarriedPlumage:"pearl"}
```

对于折衷、灰、凯克和单色实体，可查询 `Personality`，并用各物种自己的 `Sex`、`Species` 或 `Plumage` 查看外观。只有采用可遗传羽色的实体会写入 `CarriedPlumage`。
