# 和自己的鹦鹉互动

主手清空，靠近自己驯服的鸟，潜行并右击鸟身即可打开互动面板。面板显示鸟名、性格、羽色与亲密度。若鸟携带另一款羽色，也会显示携带色。鼠标悬停在羽色一行可读到完整名称与英文 ID。站直后空手右击鸟仍会切换跟随和停留。若副手拿着鸟粮或该鸟的日常食物，喂食优先。

| 亲密度 | 互动 | 在世界中能看到什么 |
| ---: | --- | --- |
| 0 | 打招呼 | 鸟朝主人点头、短叫，头顶出现音符。 |
| 0 | 轻抚 | 鸟歪头回应，头顶冒出爱心。 |
| 25 | 触指训练 | 鸟注视手的方向，向身前的绿色目标点探喙。 |
| 45 | 伸翼 | 鸟在原地舒展双翼，随后慢慢收拢。 |
| 65 | 举爪击掌 | 主人挥手发出提示，鸟抬起一只爪回应。 |
| 85 | 转一圈 | 鸟在原地交替迈步，转一整圈。 |

主人每喂一份鸟粮增加 5 点亲密度，优质鸟粮每份增加 15 点，上限 100。达到门槛后相应按钮自动解锁，发动动作会保留当前亲密度。[鸟粮配方和日常照料](cages-and-care.md)

让鸟出笼并平静落地，在 4.5 格内保持视线畅通。鸟正在觅食、繁殖、洗澡、飞行或受惊时，面板会提示等待。点击可用按钮，或用 Tab 选中后按回车或空格，面板会在动作开始时关闭，让你看到鸟的完整回应。两次互动至少相隔 4 秒。随时可以用 Esc 或右上角的关闭按钮退出。

对笼体和对鸟身的操作各有用途。要领鸟出笼，按住 Shift 右击笼体。离笼后潜行空手右击鸟身，就可以选择互动。
